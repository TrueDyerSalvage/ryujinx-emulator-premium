## 🪜 Instalación Paso a Paso

### Paso 1 — Punto de Restauración

Antes de empezar: **Panel de Control → Sistema → Protección del Sistema → Crear**.

### Paso 2 — Instalar .NET 8.0

Descarga e instala el **`.NET 8.0 Desktop Runtime`** desde el sitio oficial de Microsoft.

```bash
dotnet --list-runtimes
```

### Paso 3 — Desactivar Defender Temporalmente

**Seguridad de Windows → Protección contra virus → Administrar configuración → Protección en tiempo real → Desactivar**.

Añade una exclusión:

```
Configuración → Privacidad y seguridad → Seguridad de Windows
→ Protección contra virus → Exclusiones → Agregar carpeta
```

### Paso 4 — Extraer el Paquete

Clic derecho en el archivo → **Extraer todo…** → elige `C:\Ryujinx-Premium\`.

### Paso 5 — Ejecutar como Administrador

Clic derecho en `RyujinxPremium.exe` → **Ejecutar como administrador**.

> 💡 Si aparece SmartScreen: **Más información → Ejecutar de todas formas**.

### Paso 6 — Asistente de Configuración

Al iniciar por primera vez, el asistente Premium te guía:

1. 🌐 Selección de idioma (Español disponible)
2. 🎮 Detección automática de mandos
3. 🖥️ Detección de hardware (GPU/CPU)
4. 🚀 Aplicación del perfil recomendado
5. 🎨 Selección de tema visual

### Paso 7 — Instalar Firmware

**Herramientas → Instalar Firmware → Instalar desde ZIP**. Selecciona el archivo de firmware.

### Paso 8 — Cargar Claves

Coloca `prod.keys` y `title.keys` en:

```
%APPDATA%\Ryujinx\system\
```

### Paso 9 — Añadir Juegos

**Archivo → Cargar aplicación desde archivo…** o arrastra el NSP/XCI.

### Paso 10 — Configurar Gráficos Premium

**Opciones → Configuración → Gráficos**:

| Ajuste | Recomendado |
|--------|-------------|
| Backend | Vulkan |
| Escalado | 2x (1440p) |
| VSync | Activado |
| Filtrado anisotrópico | Automático |
| Caché de shaders | Activada |

### Paso 11 — Restaurar Seguridad

Reactiva Defender y añade `C:\Ryujinx-Premium\` a exclusiones.

### Paso 12 — Verificación Final

Lanza un juego y confirma que funciona correctamente.

## 🛠️ Solución de Problemas

| Problema | Causa | Solución |
|----------|-------|----------|
| ❌ No inicia | Falta .NET | Instalar .NET 8.0 |
| ❌ Pantalla negra | Driver GPU | Actualizar drivers |
| ❌ Juego crashea | Claves ausentes | Verificar prod.keys |
| ❌ FPS bajos | CPU saturada | Activar multi-core |
| ❌ Sin audio | Backend erróneo | Cambiar a OpenAL |
| ❌ Mando no detectado | Driver USB | Reinstalar drivers |
| ❌ Stutter de shaders | Caché compilando | Esperar compilación |
| ❌ Error firmware | ZIP corrupto | Redescargar |
| ❌ Error Vulkan | GPU antigua | Usar OpenGL |
| ❌ Save no carga | Ruta errónea | Revisar carpeta |

## ❓ Preguntas Frecuentes

**¿Ryujinx Premium es legal?**
El emulador es legal. Los juegos y el firmware deben obtenerse legalmente.

**¿Necesito una Nintendo Switch?**
Sí, para extraer tu propio firmware y claves.

**¿Funciona a 60 FPS?**
Depende del hardware y del juego.

**¿Hay multijugador en línea?**
Limitado — vía Ryujinx LDN, no servidores oficiales.

**¿Puedo usar mis partidas?**
Sí, con herramientas de transferencia de saves.

**¿Soporta amiibo?**
Sí, vía NFC emulado.

**¿Qué backend es mejor?**
Vulkan para GPUs modernas, OpenGL para antiguas.

**¿Se actualiza solo?**
Sí, la edición Premium incluye actualizaciones automáticas.

**¿Funciona en portátiles?**
Sí, con GPU dedicada.

**¿Cuántas veces se actualiza?**
Con frecuencia — varias builds por semana.
